# 小票打印、整桌账单与营业日报表

## 使用入口

- **订单管理 → 小票**：预览并打印指定订单。
- **桌台账单 → 查看账单 / 打印**：汇总同一次开台的首次点单、加单、团购兑换及各付款人的支付记录。
- **桌台管理 → 本桌账单**：查看当前开台消费。
- **小票打印**：设备、固定版式、图片、打印任务和原版本补打。
- **数据报表**：独立左侧入口，查看交互图表和分页明细，选择营业日期或精确起止时间，导出十个工作表的 Excel；超级管理员还可设置默认营业时段。

订单查看权限同时允许查看账单及打印。设备绑定、固定模板及图片上传仅超级管理员可配置。经营中心和数据报表分别授权；超级管理员始终可访问报表，管理员或店员需在账号管理中明确获授“数据报表”权限，才能查询和导出，包括成本、毛利及付款人手机号等明细。仅有经营中心或订单权限不能访问报表，仅有报表权限也不会获得经营中心或订单管理权限；现有账号不会自动新增报表权限。营业时段、门店时区及导出标题仅超级管理员可修改，其他报表账号只调整本次查询范围。打印结果人工核对允许超级管理员或管理员处理。小票不包含进货成本、利润、完整手机号或平台密钥。

## FP-V3-WH 连接飞鹅云

1. 在飞鹅中国站开放平台注册账号，取得 **USER、UKEY**。设备贴纸上的 **SN、KEY** 是另一组设备信息。
2. 超级管理员在“接口配置”填写飞鹅 USER、UKEY、区域 `china`。也可通过 `.env` 的 `FEIE_USER`、`FEIE_UKEY`、`FEIE_REGION` 配置，环境变量优先。
3. 在“小票打印”新增设备，填写名称、SN、KEY，FP-V3-WH 选 **58mm、不带切刀**。
4. 确认打印机已按厂家说明连接 Wi-Fi 并能访问飞鹅服务，设置 `FEIE_PRINTING_ENABLED=1`，点击“绑定飞鹅”。系统仅在官方回执包含该设备成功项时记录绑定。
5. 点击“查询设备”与“测试打印”，现场核对中文、金额、换行、走纸和二维码扫码效果。接口接受不代表已经出纸，要再查询任务结果。

新接入使用 2026 年迁移后的独立 HTTPS 接口，如 `/Api/Open/printMsg`、`printerAddlist`、`queryOrderState`、`queryPrinterStatus`。签名为官方 `SHA1(USER + UKEY + 秒级时间戳)`，服务端提交表单，密钥不会发往浏览器。亚太、欧洲账号可选择对应区域，不能把不同区域的账号混用。

设备 KEY 在后台留空编辑时保留，后台查询不返回其值。变更飞鹅账号或区域后需重新确认设备绑定。数据备份会移除 UKEY、设备 KEY 和绑定状态，恢复后未完成任务必须先核对，不自动重发旧队列。

## 固定抬头和末尾

后台支持抬头、末尾各八行文字，调整顺序、左 / 中 / 右对齐、普通 / 加粗 / 放大，配置联系方式及页脚。Logo、小程序码支持上传 PNG、JPEG、WebP，最大 2MB，保存与商品图片共用的本地或对象存储。套餐组成可选择展示，商品与支付区始终由订单生成。

抬头的“小票店名”可单独设置，最多 40 个字；留空时跟随当前后台门店名称。设置页的示例小票展示当前编辑内容，点击“保存固定版式”后才应用于订单打印。指定订单和整桌账单的新预览、系统打印及云打印统一使用这套已保存的设置，已结束桌台也不会退回开台时的旧店名。抬头文字行是店名下方的附加文字，修改主店名请使用“小票店名”输入框。

已结束账单的历史门店名称及最终财务快照继续保留；新小票单独保存实际使用的抬头。门店改名后须重新打开新预览，旧预览不能直接提交云打印；原件预览和补打始终使用原任务保存的店名及模板，不随当前设置改变。

**FP-V3-WH 支持 Logo，公开的标准小票接口调用设备预置位图，并不提供上传图片 URL 后自动同步设备的接口。** 更换图片后，须在飞鹅助手设置同一图片、等待设备接收，再点本后台“确认设备位图”。软件保存上传和排版，人工确认用于记录设备实际图片的对应关系，不冒充平台自动同步。

同一台打印机只有一个预置 Logo / 位图，云打印可选：

- **抬头 Logo + 末尾链接二维码**：Logo 由 `<LOGO>` 打印；末尾填写有效的小程序 HTTPS / 微信跳转链接，使用 `<QR>`。上传图片不会被误当作链接内容。
- **抬头文字 + 末尾上传的小程序码位图**：上传真实门店码，在飞鹅助手把它设置为设备预置位图，关闭另一个抬头 Logo，末尾选择“设备预置小程序码图片”并确认。这种格式在票尾调用 `<LOGO>`。
- **两张不同上传图片同时展示**：后台保留完整预览及“系统打印完整图片版”；该路径使用浏览器和本地已安装的打印设备 / PDF，不经飞鹅云。标准 `Open_printMsg` 不能同时下发两个独立位图，不能承诺云打印上述两张上传图片。若厂家另外提供图文接口，可在当前模板结构上继续适配。

使用系统打印时，在打印驱动中选择实际 58mm / 80mm 纸张、关闭浏览器页眉页脚并核对边距；页面按所选纸宽排版，纸张走纸由本地驱动决定。

位图位置或图片内容变化前须处理该设备未完成任务，避免排队中的旧票使用新图片。实际预置图片效果、二维码可读性及打印纸边距需要在此设备上验收。原生 QR 一张飞鹅订单最多一个；无切刀机型只走纸，不发 `<CUT>`。

## 账单与打印任务

- 一次 `table_session` 对应一个稳定账单号，不按桌号或付款人合并，不把第二批顾客合入第一批消费。所有子订单保持独立，支付、退款、配送、库存逻辑继续使用原单。
- 进行中的整桌清单标明状态及打印时间。已付款商品汇总，相同商品、单价、单位及套餐组成才合并数量。未付款商品单独列示，不计已收金额；取消单也不计收入。
- 套餐按套计价，组成货品缩进显示且不重复收费。会员优惠、优惠券和支付渠道按已保存金额汇总，不重新给整桌套用优惠。
- 美团小票的金额来自平台 `realAmount` 商家核销记账估算，不代表消费者实际购券价或平台实际到账。抖音来自券实付 `pay_amount`。平台实付未知时不编造。
- 结束桌台必须完成待付、配送、服务需求及团购 / 退款异常核对。结束时保存最终账单快照，之后有调整的新预览作标记；旧打印任务的内容、模板、金额快照不变。
- 小票提交前核对预览版本。双击及重复请求返回原任务，同版本正常打印不会悄悄再发一份。明确补打复制原任务快照，加“补打”标记并记录原因。
- 按 UTF-8 字节数分段，每段少于飞鹅 5000 字节，按设备串行发送。每段提交前保存“发送中”及有效期，再保存平台订单号。整个任务只有所有段有完成依据才显示完成。
- 飞鹅接受时显示“待出纸确认”，查询接口为 true 后显示“飞鹅确认已打印”。超时且平台订单号未知时保留待核对，不盲目重发。明确拒绝可继续未发送部分，不重复前面已接受内容。
- 云任务设置 15 分钟打印有效期。过期但出纸回执不明仍需人工核对，不能自动认定未打印。管理员可确认已发送部分已出纸并继续未发部分，或在原任务过有效期后停止等待、再决定补打。人工确认与平台确认分别标记，不等同平台回执。

新订单和库存日志保存货品单位快照。历史订单缺少单位快照时使用“件”，库存流水标明历史单位未留存，不按后来修改的单位重解释历史数量。

## 营业日与文件名

默认门店时区 `Asia/Shanghai`，营业开始 **12:00**、结束 **06:00**。结束时间不晚于开始时间时归次日，因此：

`2026-10-13 12:00 ≤ 业务时间 < 2026-10-14 06:00`

导出默认命名：**`营业明细-202610131200-202610140600.xlsx`**。后台可改标题、时区（北京时间 / 马来西亚时间 / UTC）、默认起止钟点；查询时也可直接选择实际起止日期时间。采用门店时区，不依赖宝塔服务器的系统时区。结束时刻不含，连续查询不会把边界交易计算两次。单次最多 31 天、10000 笔订单，超限明确要求缩短范围，不静默截断。

时间范围包含什么就统计什么；范围之外的收款、结算或退款需选择相应实际时间查询。开台跨范围时，整桌累计金额与本范围金额分开，不能把整桌累计金额再次加入当天收入。

## 交互图表与明细

首页突出净销售额、商品毛利估算、毛利率与外部净收款。毛利率等于商品毛利估算除以净销售额；净销售额不为正、历史退库成本未知时不计算。经营净利润标记“费用待补充”，目前没有完整人工、房租、水电、税费和平台费用台账。

- 快捷选择本营业日、近7个营业日、近30个营业日，日期按门店时区和营业开始钟点确定；也可展开精确起止时间。修改时间后须先查询，导出使用已查询的范围。
- ECharts 在进入报表时按需加载，资源与项目打包，不依赖外部 CDN。销售 / 毛利趋势支持悬停、图例切换和时间缩放；不超过24小时按实际小时段展示，更长范围按营业开始钟点分日，首尾截断，金额与整段统计一致。历史成本未知的毛利点保留缺口。
- 点击趋势的日期 / 时段或销售来源，筛选下面的消费订单；点击外部收付渠道，切换到对应收付流水。图表筛选只影响下方明细，上方指标仍是完整周期。清除筛选恢复当前明细类型的全部记录。
- 消费订单支持手机号或订单号查询，按本期支付、成功退款、待审核 / 处理中退款、待支付、已取消筛选。分页不静默截断，详情保留付款身份、原价 / 优惠 / 赠金、各支付渠道、本期退款冲减及成本 / 回库说明。只有报表权限也能查看报表详情，不要求额外订单权限，页面不提供退款操作。
- 退款提醒查看本范围的待审核申请和未完成退款；团购提醒查看本期核销的待登记记录，已知差额与预计未知数量分开显示。团购页保留截止期末登记累计、本期各次到账 / 调整和预计金额。
- 商品销售前50项、消费支付记账渠道和每日经营表格在“商品销售、消费支付渠道与每日经营明细”中展开。Excel 包含完整范围，不受页面分页、关键词或图表点击条件限制。

报表查询接口为 `GET /api/admin/reports`；分页明细为 `GET /api/admin/reports/details`，参数 `kind=orders|flows|redemptions`、`q`、`status`、`source`、`channel`、`page`、`pageSize`（最多100）。趋势下钻使用 `segmentStart` / `segmentEnd`，必须落在本次 `startAt` / `endAt` 内。订单详情为 `GET /api/admin/reports/orders/:id`，仅返回当前范围的关联订单；上述接口均沿用独立数据报表权限。

## 十个 Excel 工作表与口径

1. **营业总览**：四张核心指标、销售和收款分别拆解、来源贡献、成本与毛利、异常及口径说明；先看这一页即可了解所选周期。
2. **订单明细**：本范围创建、付款或发生退款 / 待审核申请的订单，附商品摘要、本期成功退款冲减、本期净销售贡献和处理中数量。付款人旁列完整手机号和固定会员 ID，按该订单 `payer_user_id` 关联；新付款订单使用身份快照，旧订单无快照明确使用当前档案，未绑定手机号标注，固定会员 ID 不随昵称或手机号变化。待付 / 取消可查，只有成功付款计销售。
3. **桌台账单**：开台 / 结束时间、状态、本期订单和净销售贡献、含跨期及赠金的整桌累计净消费，两列不混加。
4. **商品明细**：套餐按套、单品按单位，已知优惠券按整分钱分摊，与订单结算对应。商品金额不能对应的旧记录留空并提示，退款不猜测分摊到某个商品。
5. **收付流水**：成功付款、退款、充值、团购到账及调整。未完成退款单独列申请金额，确认金额留空，不冲减收入。
6. **退款明细**：申请 / 确认金额、退本金 / 赠金 / 外部款及券记账、原付款时间、完成时间、库存处理及实际回库成本，保留待审核申请；历史未留存库存处理方式时不猜测。
7. **团购结算**：核销记账、预计到账、截至所查期末已登记累计、最后登记时间、本期各次到账及调整、已知待登记差额；预计未知留空。已知差额不小于0，累计与本期金额不能重复相加。
8. **基础货品流水**：套餐展开后的真实出入库、退库、库存调整、赠送、报损、关联订单与单位快照。
9. **会员充值记录**：实际充值款、到账本金、赠金、收款渠道、稳定会员ID及当前手机号 / 昵称。充值未保存身份快照，明确标记当前资料，不声称是充值时的手机号。
10. **统计说明**：完整统计定义、未知值含义，以及订单 / 整桌 / 商品 / 来源 / 外部渠道 / 团购到账与首页的金额核对；差额0.00仅说明内部一致，不代表平台对账验收。

订单号、手机号、会员 ID / 券码类标识使用文本，保留前导零和长 ID；金额与时间是原生可筛选单元格。表头冻结、自动筛选、中文状态和两位小数。完整手机号向有订单权限的后台账号展示，也包含在超级管理员及获授数据报表权限账号的报表导出中，顾客小票不增加手机号。导出是当时的账务快照，界面和 Excel 使用同一个查询 / 统计函数。

- **净销售额** = 本范围成功订单结算额 − 赠金抵扣 − 本范围成功退款中的销售额冲减。返还赠金单独列示，不再冲减一次现金收入。
- **外部净收款** = 本范围外部订单付款 + 充值款 + 已录入到账日期的团购结算 / 调整 − 外部退款。储值本金、赠金内部扣减和团购核销记账不重复记新收款。
- 付款按服务端业务确认时间统计，退款按完成时间统计，保留原订单日期。跨日退款影响退款完成时段，不倒扣原销售日。原微信对接历史 `paid_at` 是确认时间，并不追认平台未保留的历史支付时间。
- 新退款在事务内保存实际退库成本差额，成本冲回归退款完成时段。旧记录仅在退库数量及日志能明确归属时回填；未知成本和毛利留空，不代入零。已交付退款保留实际耗用成本。
- 团购实际结算需录入到账日期。修正累计实际结算时记录差额调整，同一请求去重，保留审计记录。截止期末累计按所有早于查询结束时刻的有日期流水计算，未来登记不倒灌历史；本期金额只取本范围的到账和调整。旧结算没有日期时不猜测到账日。
- 商品毛利估算以系统订单成本快照和赠送报损为基础，未扣房租、人工及未记录的平台费用，不称净利润。

## 退款成本与班次

新退款默认不回库，已开瓶 / 已消费货品保留成本；管理员可按原订单基础货品选择实际回库数量，包括已送达后收回的可售货品。只有这些数量的成本在退款完成时冲回，不另记重复报损。停止配送数量单独控制履约。具体选择与示例见 [单门店营业操作](SINGLE-STORE-OPERATIONS.md)。

现金其他收支只影响班次钱箱，不加入销售额。班次归属按系统确认时刻，跨日营业报表仍按所选营业时间范围统计；交班不自动结束桌台账单。团购实际结算的到账日期与录入确认班次分别保留。
