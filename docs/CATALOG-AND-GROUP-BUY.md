# 基础货品、套餐与团购兑换

## 使用顺序

1. 超级管理员在“商品与库存”配置基础货品的单位、进货成本、补货线、目标库存、每箱数量。只用于套餐的货品选择“仅供套餐使用”。
2. 新建组合套餐，选择组成货品及每套数量，设置小程序售价、会员价、附加成本和参考总成本。计算成本 = 组成货品进货成本 × 数量 + 附加成本；参考总成本用于校核，不重复计入成本。
3. “团购核销”建立平台套餐 ID 到本店组合套餐的映射，填写参考售价与预计费率。抖音普通团购验券准备返回的 `sku_id` 就是商品 ID；美团直连查券返回的 `dealId` 是团单 ID，可选 SKU 字段对应远端整套收银 SKU。匹配使用平台 ID，不按名称猜测。
4. 顾客扫描桌台码，在点单页点击“团购兑换”，选择平台、粘贴券码、查询并确认兑换。券码按文本保存，保留前导零。
5. 没有平台权限时，收银员先在美团 / 抖音商家端完成真实核销，再在“平台核销后录入配送”中选择套餐、桌台和顾客，填写核对后的券金额并确认。系统生成订单、扣减货品库存，交给现有服务工作台配货配送。

新建收银账号默认包含团购核销权限。已有收银账号的自定义权限保留，需超级管理员在“账号管理”中授权“团购核销”。

旧版“套餐”分类商品不会自动转换为组合套餐，已有库存和历史订单保留；需要管理员确认实际包含的货品后配置。商品仍在购物车或未完成订单中时，不能转换类型。已建立平台映射的套餐不能修改组成；内容变化请新建套餐并使用新的平台套餐 ID，保留旧套餐供历史券兑换。

## 库存与查询

- 基础货品保存账面库存和预占库存，可售 = 账面 − 预占。套餐可售数量为各组成货品 `可售 ÷ 每套用量` 向下取整后的最小值。多个套餐共用货品，其可售数量不能相加。
- 购物车、收银下单和团购兑换统一检查组成货品总需求，单品与多个套餐混购也不能超卖。
- 支付 / 核销成功记出库，送达时不重复扣库存。待支付订单和结果未确认的核销预占货品。
- 商品列表支持关键词、类型、低库存、缺货筛选；明细显示相关套餐、近 30 天各渠道消耗和库存流水，日期筛选最多展示 500 条。旧版没有记录的销售流水不进行猜测补录。
- 可按箱进货，按基础单位管理库存；CSV 可导出库存。批量盘点使用“货品 ID, 盘点数量”，先预览再提交，库存 / 预占变化会要求重新预览。盘点数量指**未分配的账面货品**，已支付但未送达的货品已出库，应单独核对待配货清单。
- 套餐订单保留组成版本、货品、单价和成本快照。服务工作台按组成货品配送，可分批。金额按整分钱分配；遇到尾差，同一货品可能拆成两个价格明细，数量、总金额和成本均保持一致。
- 库存流水包括新订单出库、退款退回、赠送 / 报损、积分奖品、调整和盘点。赠送 / 报损和积分奖品请选择基础货品。

## 平台接入状态与限制

**无真实商户凭证和权限时，顾客自助兑换不可用，系统不会模拟平台成功。**

- 美团：已实现餐饮品牌直连业务 79 的券码查询、预核销、单张固定套餐核销及原订单历史核对。需开通对应能力、绑定收银门店、配置整套 SKU 和凭证，并完成实券联调后设置 `MEITUAN_REDEMPTION_ENABLED=1`。默认关闭，不进行真实核销模拟。详细配置和接口范围见 [美团券码自助核销接入](MEITUAN-REDEMPTION.md)。
- 抖音：已按公开文档实现 client_token、明文券码验券准备和单张固定团购套餐验券。默认关闭，需申请“团购核销”、完成来客商家授权、配置 `DOUYIN_POI_ID`，确认顾客自助场景可用并完成实券联调后，设置 `DOUYIN_REDEMPTION_ENABLED=1`。
- 抖音验券使用准备接口返回的 `verify_token` 和 `encrypted_code`；本地 requestId 是独立的请求去重标识。一次查询中多个券不能重复使用已经开始核销的准备 token，需重新查询剩余券。
- 本版只支持固定套餐，排除代金券、次卡、储值卡、提货券和多选套餐。抖音检查返回的有效期、使用时段、不可用日期和本桌 / 本人张数限制，错峰券要求服务员核对。美团检查返回的有效期和单次用券上限，并执行平台预核销。平台仍会做最终核销校验。
- 团购订单不再收微信、现金或会员余额，不叠加小程序会员折扣、优惠券、赠金。券金额、预计结算和实际结算分开保存，未知到账金额不记为 0。美团使用平台 `realAmount` 商家实收估算值（未扣手续费），抖音使用 `pay_amount` 券实付金额。
- 实际结算由超级管理员填写累计到账金额和到账日期时间，按设置的门店时区归属报表。修正累计金额会保存差额调整，重复请求不再次计入；旧记录只有金额但没有到账日期时，不猜测日期，需补录。
- 核销金额计入对应消费销售，实际到账单独列为平台结算；核销记账不重复加入外部收款。商品毛利估算减实际商品净成本和赠送报损，**尚未扣未记录的平台费用、房租和人工**。预计费率仅用于团购预计结算，不代表真实到账。跨日统计与完整 Excel 口径见 [小票、账单与营业报表说明](PRINTING-AND-BUSINESS-REPORTS.md)。

组合套餐在顾客清单和小票中按套计价，可展示包含的货品；基础货品库存流水按实际消耗数量展开，不把套餐价格再次加入组成商品收入。团购订单和本次开台的其他加单一起进入桌台消费账单，各来源订单及付款信息独立保留。

## 核销异常与撤销

正式核销请求超时、平台返回不明确结果或服务进程中断时，保留预占库存，不生成配送订单、不自动重试一次新的核销。美团定时核对原订单验券历史，也可在后台点“查询美团结果”；只有本店原订单、套餐、券码、状态和金额一致才自动恢复订单。仍不明确时，管理员核实平台记录：成功时填写核销凭证并生成订单，平台明确未核销时释放库存。美团正式核销尚未发出时的查券 / 预核销失败会释放本次本地预占。已保存成功凭证但本地订单尚未生成的记录，启动后由后台恢复任务生成订单；已生成订单不会再重复扣库或派单。结果待核对的桌台不能结束。

顾客不能用余额 / 微信退款接口退团购订单。需先在原平台撤销核销或退款，再由管理员在团购记录中填写平台凭证同步撤销；仅支持整套货品未送达、无配送在途的订单，待取批次会取消，货品退库、团购收入冲回一次。部分交付订单需人工核对，不自动退库。已撤销券不能在本版重新兑换同一券，需收银核对新的有效券。

超级管理员在“账号管理 → 修改密码”中可直接设置管理员 / 店员密码，无需原密码，目标账号已有会话失效。已登录超级管理员修改自己的密码也无需旧密码，保留当前会话并注销其他设备；普通账号修改自己的密码仍需原密码。所有重置都有操作日志。
