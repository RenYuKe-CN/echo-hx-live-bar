# 美团 / 抖音在线核销已移除

本版本不再提供顾客小程序查券、预核销、在线核销和远端核销历史查询，也不使用美团 / 抖音开放平台密钥。原 `MEITUAN_*` / `DOUYIN_*` 启用开关和凭证不再读取；服务器已有设置不会自动删除，但不能再启用这些接口。

当前流程：收银员在美团 / 抖音商家端核销成功 → 收银点单选择“团购核销” → 绑定顾客手机号和桌台 → 选择本店对应套餐 → 确认实际券金额（无需券码） → 确认生成配送订单。套餐配置无需平台套餐 ID，组成货品、成本、库存、预计结算和实际到账分别保留。

旧版小程序查券、确认核销、后台手工核销入口和美团结果重查接口返回 HTTP 410 及改用收银台的提示，不会访问团购平台。更新服务器后还需重新发布小程序，移除旧页面入口。

历史已成功记录、平台 ID、订单和结算数据不删除；结果未知的旧记录继续保留库存预占，由管理员在“团购记录”核对商家端凭证后人工处理。已保存成功结果但未生成订单的旧记录仍可本地恢复，不会再次核销；同一订单不会重复扣库。详细操作见 [基础货品、套餐与收银团购登记](CATALOG-AND-GROUP-BUY.md)。
