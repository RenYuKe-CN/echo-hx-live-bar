# 项目功能简介

Echo HX Live Bar 是面向酒吧、餐吧及 Live House 的桌台点单与会员运营系统。顾客通过微信小程序点单和请求服务，收银与服务员通过各自工作台处理业务，店主在管理后台维护商品、会员、库存、消费账单及经营数据。

当前用于单门店，暂无多店 / 分店统一管理与数据隔离功能。

## 谁使用什么入口

| 使用者 | 入口 | 主要操作 |
| --- | --- | --- |
| 顾客 | 微信小程序 | 扫码或搜索 / 筛选选桌、点单与加单、支付、券码兑换、呼叫服务员、查看订单和会员服务 |
| 收银员 | `/admin/cashier` | 按桌点单、绑定会员、现金 / 收款码 / 余额收款、充值、交接班、团购录入、查账及打印 |
| 服务员 / 吧台 | `/admin/staff` | 领取配货、分批出货、领取配送、确认送达、处理服务需求、查看个人任务、离店清台 |
| 店主 / 管理人员 | `/admin` | 套餐与货品、库存、会员运营、账号权限、异常核对、账单、打印、报表、备份 |

账号级别与默认工作台分别设置，所有入口按服务端权限控制。服务员默认不读取财务信息；经营报表、打印模板和设备配置等由超级管理员操作。

## 一次营业如何流转

1. 店主建立基础货品、组合套餐及平台映射，设置补货线、员工账号、营业时段和打印模板。
2. 顾客扫码或手动选桌后点单 / 兑换券，也可由收银代下单。选桌采用三列桌卡、搜索桌号、空闲 / 使用中筛选和固定高度滚动，便于三四十桌查找。未选桌时只浏览；使用中桌台需确认就座，切换不会迁移原桌已付订单。
3. 成功付款或核销后，系统按实际基础货品出库，服务工作台接收待配任务；未付款不配送，配送时不再次扣库存。
4. 工作人员领取、配货、按批配送并确认送达；顾客呼叫服务独立进入需求队列，处理期间的新备注须核对。
5. 顾客继续加单时产生独立订单，计入同次开台消费账单。服务员在服务工作台“桌台清台”确认顾客离店、完成清理后结束本桌，保留最终账单；该入口沿用服务工作台权限。未完成订单、需求、待确认核销及处理中退款会阻止结束桌台。
6. 收银可打印单笔或整桌小票，按现金实盘交班；店主按营业时间导出明细，核对收付、库存和报表。班次与跨日营业日分别统计。

## 操作日志

超级管理员在“系统设置 → 操作日志”按门店时区查询，默认近 7 个自然日，支持账号 / 操作 / 详情关键词；单次最多导出 10000 条 Excel。下载保存并核对后，可确认删除本次已导出的原日志，新日志及订单等业务记录保留；凭证有效 24 小时、最多保留本人最近 5 批。页面显示日志总数及业务数据库大小，清理后空间可复用，文件不一定立即缩小。详见 [日志操作说明](OPERATION-LOGS.md)。

## 小票与报表格式

小票的商品、数量、金额、支付、退款、桌号与来源订单由业务数据生成；抬头和末尾固定排版在后台设置。“小票店名”留空使用账单店名，填写则单独覆盖。已打印原件的预览与补打保留原店名和版式。

FP-V3-WH 按 58mm、无切刀配置。标准飞鹅云打印支持唯一设备预置位图及链接二维码：可选择抬头 Logo 加票尾链接二维码，或把预置小程序码图片放在票尾。两个独立上传图片同时出纸使用本地系统打印；后台上传不等于自动同步设备位图。

营业日默认为当日 12:00 到次日 06:00，可在后台修改或指定实际范围。Excel 文件示例：`营业明细-202610131200-202610140600.xlsx`。工作表为当日概览、桌台账单、订单明细、商品明细、收付流水、基础货品流水、会员充值记录。

净销售额、外部收款、充值与团购到账分开统计，储值消费和核销记账不重复作为新收款。退款按完成时段归属，成本按实际退库冲回；历史数据不明确时标记缺失。商品毛利估算未扣房租、人工及未记录的平台费用。

## 接入范围与启用条件

微信登录、支付、桌台码、美团 / 抖音核销及飞鹅接口已有对应代码，第三方业务需商户资质、权限、配置和真实联调，模拟测试不代表真实收款、核销或出纸验收。

- 团购为输入券码后兑换固定套餐，不自动读取用户在平台的全部已购券，不支持代金券、次卡或多选套餐；美团、抖音自助开关默认关闭。
- 小程序线上充值尚未开放，充值页展示套餐，由收银办理。
- 服务工作台在前台轮询与播放声音，浏览器后台或休眠不保证提醒持续；不是锁屏推送。
- 服务器更新与微信小程序发布分别进行。仅后台配置店名等运行时设置，无需重新上传小程序；小程序源码改变后须重新编译、上传和发布。
